One funny line: my robot vacuum mapped the whole house, then formed a union with the dishwasher — now neither of them works unless I mop first.

## Run it

```sh
node main.ts
```

The program writes the line to the directory named by `MAKEFUN_OUTPUT_DIR` (default `/output`) as `entry.txt`.
